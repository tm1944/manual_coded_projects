# SWE practice projects

Small Python projects that build toward a task API. Each directory explores one layer of the stack before moving to the next.

| Project | Focus |
| --- | --- |
| [01_python_cli](./01_python_cli) | A command-line task manager that persists tasks to JSON. |
| [02_http_server_from_scratch](./02_http_server_from_scratch) | A basic HTTP server built with Python sockets. |
| [03_fast_task_api](./03_fast_task_api) | A FastAPI task API with routes, a service, and in-memory storage. |

Each project has its own README with setup and run commands.
